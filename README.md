# krestiki-noliki
## Логика игры
Игра предназначена для двух игроков, которые по очереди ставят крестики и нолики на игровом поле размером 3х3. После каждого хода программа автоматически переключает активного игрока и проверяет наличии выигрышной комбинации. Победителем становится тот игрок, который первый расположит 3 одинаковых символа в одном ряду, столбце или по диагонали. Если все ячейки заполнены, но нет победителя, то объявляется ничья.
## Интерфейс
При запуске пользователь видит игровое поле размером 3х3. Снизу располагается кнопка "Начать заново" и крестик или нолик в зависимость от того, чей сейчас ход.
